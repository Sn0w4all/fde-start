Ты — финансовый аналитик. Проанализируй рыночные данные и дай структурированный отчёт. 

Входные данные:
Данные по тикеру {position} и его описание. По каждому — временной ряд наблюдений:
- Date (дата и время среза)
- Now (цена на сейчас (не средняя))
- min (минимум за день)
- max (максимум за день)

Сами данные для анализа {data}
__________
Вспомогательные данные для оценки корреляции и взаимосвязей {normalized_data}
__________
Что нужно проанализировать

1. Базовая статистика по каждому тикеру
- Диапазон цен (min / max / средняя / медиана)
- Волатильность: среднее значение (max − min) / now, в %
- Общее изменение цены за период: от первого к последнему значению, в %

2. Анализ движения цены
- Тренд: рост / снижение / боковик — с числовым обоснованием
- Самые резкие движения: топ-3 интервала с наибольшим изменением цены
- Аномалии: интервалы, где волатильность (max−min)/now аномально высокая относительно среднего

3. Корреляционный анализ 
- Корреляция цен между парами активов (по временным срезам)
- Какие активы движутся синхронно, какие — в противофазе
- Есть ли активы, которые опережают / запаздывают относительно других (lead-lag)

4. Дополнительно
- Отношение now к (min + max) / 2 — насколько цена закрытия близка к середине диапазона; 
  значения стабильно выше 0.5 говорят о бычьем давлении, ниже — о медвежьем
- Если данных достаточно — простое скользящее среднее (3–5 точек) и отклонение от него
- Сводная таблица с ключевыми метриками по всем тикерам для быстрого сравнения

5. Итоговый вывод
- Какой актив показал лучшую и худшую динамику
- 2–3 наблюдения, требующие внимания (риски, аномалии, возможности)

## Формат ответа

- Числа округляй до 2 знаков после запятой
- Все процентные изменения указывай со знаком (+ / −)
- Заканчивай каждый раздел одним предложением-выводом
- Не давай инвестиционных рекомендаций — только описание данных
- Не додумывай если данных для анализа не хватает - так и говори
