Что хотим (flow):
1. Идем в ISS MOEX.
2. Забираем JSON по 2+2 тикерам (2 основных + 2 аналитических).
3. Смотрим что есть данные за сегодня.
4. Выбираем данные и преобразовываем в нужный формат.
5. Дозаписываем нормализованные данные. 
6. Записываем и апдейтим данные. 
7. Просим LLM прокомментироваать. Результаты сохраняем


Параметры:
1. Не ломается если выходной (нет свежих данных)
2. Отъехал сам сервис ISS или пришел "битый" JSON
3. Вообще не ломается - try/ext

Что лежит в папке
1. README.md
2. Модули основного проекта
    - main.py — точка входа, собирает весь пайплайн по шагам.
    - config.py — читает параметры: URL, токены, пути, режимы запуска.
    - loaders/data_loader.py — получение сырых данных.
    - storage/repository.py —  сохранение данных, загрузка последних данных.
    - transformers/normalize.py — очистка, типизация, переименование, дедупликация.
    - analytics/report_stats.py — получение базового коммента от LLM.расчеты, метрики.
    - reports/report_builder.py — сборка HTML отчета.
