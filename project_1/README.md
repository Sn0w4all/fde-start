Что хотим (flow):
1. Идем в IIS MOEX.
2. Забираем JSON по 2+2 тикерам (2 основных + 2 аналитических).
3. Смотрим что есть данные за сегодня.
4. Выбираем данные и преобразовываем в нужный формат.
5. Записываем данные. считаем VARмаржу по основным и еще ряд параметров.
6. Записываем и апдейтим табличку. 
7. Просим LLM прокомментироваать.


Параметры:
1. Не ломается если выходной (нет свежих данных)
2. Отъехал сам сервис IIS или пришел "битый" JSON
3. LLM проверяет сама себя и данные на консистентность.
4. Вообще не ломается - try/ext

Что лежит в папке:
1. README.md
2.  Модули основного проекта
    - main.py — точка входа, собирает весь пайплайн по шагам.
    - config.py — читает параметры: URL, токены, пути, режимы запуска.
    - loaders/data_loader.py — получение сырых данных.
    - storage/repository.py —  сохранение данных.
    - transformers/normalize.py — очистка, типизация, переименование, дедупликация.
    - analytics/report_stats.py — получение базового коммента от LLM.расчеты, метрики, агрегации пока не делаем.
    - # (пока не делаем) reports/report_builder.py — сборка Excel, CSV, HTML или PDF отчета.
3. # (пока не делаем) Тестовые данные и юнит тесты.
